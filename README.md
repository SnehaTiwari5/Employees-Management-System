# Employee Management System

A simple and intuitive **Employee Management System** developed using **Java** and built in **IntelliJ IDEA**. This application allows for the management of employee records such as adding, updating, deleting, and viewing employee details.

## 📌 Features

- Add new employee records
- View all employees
- Search employees by ID or name
- Update employee information
- Delete employee records
- Console-based interface (can be extended to GUI or web)

## 🛠️ Technologies Used

- **Java 17** (or your Java version)
- **IntelliJ IDEA** (as the IDE)
- **Maven/Gradle** (optional, for dependency management)
- **JDBC** (if using a database)
- **SQLite / MySQL / H2** (optional, for persistence)


## 🚀 Getting Started

### Prerequisites

- Java installed ([Download Java](https://www.oracle.com/java/technologies/javase-downloads.html))
- IntelliJ IDEA installed ([Download IntelliJ](https://www.jetbrains.com/idea/))
-  MySQL or SQLite for database

### Installation
Open the project in IntelliJ IDEA

Build the project using the build tool (or manually compile via IntelliJ)

Run the Main.java file

🗃️ Database Configuration
Update your JDBC URL, username, and password in the DAO class

Run the SQL schema in your database to create the required tables
